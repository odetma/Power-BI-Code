# Skills

Reusable AI skill resources for Power BI workflows.

## Contents

| Folder | Purpose |
| --- | --- |
| [`power-bi-theme-style/`](power-bi-theme-style/) | Skill instructions and theme assets for extracting PBIP styles and creating custom Power BI theme presets. |
| [`powerbi-report-builder/`](powerbi-report-builder/) | Build and verify local PBIR pages and drillthrough with model-aware checks, Desktop reload, native warning handling, and saved screenshots. Includes setup and a source-only installer. |

For the report authoring workflow, start with the [Report Builder installation guide](powerbi-report-builder/README.md). The theme skill is complementary: use it when the task explicitly calls for theme extraction or a new style, rather than silently changing an existing report's theme.
