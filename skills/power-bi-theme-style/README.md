# Power BI Theme Style Skill

Resources for generating Power BI custom themes from PBIP files and building style presets, including dark mode variants.

## Contents

| File | Purpose |
| --- | --- |
| [`prompt.txt`](prompt.txt) | End-user prompt template for creating one combined theme with light and dark presets. |
| [`pbip-theme-extraction.md`](pbip-theme-extraction.md) | Detailed instructions for extracting styling from PBIP project files. |
| [`pbi-style-presets.md`](pbi-style-presets.md) | Guidance for Power BI theme JSON and style preset creation. |
| [`assets/starter-theme.json`](assets/starter-theme.json) | Minimal starter theme. |
| [`assets/dark-mode-starter-theme.json`](assets/dark-mode-starter-theme.json) | Dark mode starter theme with preset examples. |
| [`references/card-property-examples.md`](references/card-property-examples.md) | Common visual card/property examples for theme JSON. |

## Usage Notes

- Use the prompt and instruction files together when asking an AI agent to extract or generate a Power BI theme.
- Validate generated theme JSON before importing it into Power BI Desktop.
- Theme behavior can vary by Power BI Desktop version, especially around style presets.
